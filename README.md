# Kavir Store · فروشگاه کویر

A personal Android app store. GitHub is the database and the CDN: the catalog is a JSON file in this
repository and every APK is downloaded straight from the GitHub Release of its own project.

فروشگاه شخصی برنامه‌های اندروید. گیت‌هاب هم پایگاه‌داده است و هم محل توزیع: کاتالوگ یک فایل JSON در همین ریپو است و هر APK مستقیم از Release خودِ همان برنامه دانلود می‌شود.

**راه‌اندازی قدم‌به‌قدم (فارسی): [docs/SETUP.fa.md](docs/SETUP.fa.md)**

## How it works

```
 app repos (public)            this repo                                   phones
 ┌────────────────┐   hourly   ┌──────────────────────────────┐  raw.githubusercontent.com
 │ Release + APK  │──────────▶ │ sync-catalog workflow        │──▶ catalog/apps.json ─────▶ Kavir Store
 └────────────────┘  or ping   │  aapt2: package/version/minSdk│                              │
        ▲                      │  sha256 + signer fingerprint  │                              │ HTTPS
        └─────────────────────────────────────────────────────────── APK download ◀──────────┘
                               │ catalog/sources.json (admin)  │      (github.com/…/releases/download)
                               └──────────────────────────────┘
```

| Path | Purpose |
|---|---|
| `catalog/sources.json` | Registry: which repos are in the store, overrides, enabled/featured. Edited by the admin panel or by hand. |
| `catalog/apps.json` | Generated by the workflow; this is what every phone reads. Never edit by hand. |
| `scripts/sync_catalog.py` | Release detection, APK inspection, catalog generation, `--validate`. |
| `.github/workflows/` | `validate.yml`, `sync-catalog.yml`, `build-release.yml`. |
| `app/` | The Android app (Kotlin, Jetpack Compose, Material 3). |

## Features

- Home, categories, search, featured and recently-updated apps, app details with screenshots and changelog.
- Install / Update / Open depending on the installed `versionCode`; **Update all**; installed apps and updates tab.
- Download progress, SHA-256 check, package-name / version / signature checks, Android's own installer UI.
- Persian (RTL) and English; light, dark or system theme.
- Admin panel (GitHub token, verified against repository write access): add by repo URL, auto-detect releases,
  edit metadata, enable/disable, remove from the catalog, refresh releases.
- Works offline from the last saved catalog; handles GitHub rate limits and network errors.

## Build locally

```bash
gradle :app:assembleDebug -PappVersionName=1.0.0 -PappVersionCode=1   # needs Android SDK, JDK 17, Gradle 8.10+
python3 scripts/test_sync.py                                           # catalog tooling tests
```

Releases are built and signed by GitHub Actions; see the setup guide for the four signing secrets.

To fork this for another account, set `-PcatalogRepo=owner/name` (the workflow does this automatically).
